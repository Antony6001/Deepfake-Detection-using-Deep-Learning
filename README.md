# Deepfake Detection using Deep Learning

A deep learning system that classifies face images as **REAL** or **FAKE**, built with PyTorch. The project compares a custom CNN, transfer learning on pre-trained backbones, and a Vision Transformer, then evaluates all three for accuracy, robustness across demographics, and interpretability.

**Domain:** Computer Vision & AI Safety

---

## Problem Statement

Deepfakes — synthetic media generated by models like GANs — are increasingly difficult to distinguish from authentic photos. This project builds an end-to-end pipeline that:

- Classifies face images as REAL or FAKE, and surfaces gender / age-group context alongside each prediction
- Targets **90%+ accuracy** and **0.85+ F1-score** on the test set
- Handles class imbalance (3,767 FAKE vs. 2,790 REAL)
- Generalizes across demographic groups (age, gender)
- Provides interpretability through visualization (Grad-CAM, saliency maps)

## Dataset

| **Total samples** | 6,557 images |

**Columns:**

| `label` | Target variable — REAL / FAKE |
| `gender` | Male / Female / Unknown |
| `age_group` | 18–25, 26–35, 36–50, 50+ |

Images are referenced by URL rather than shipped directly, so the pipeline includes a download step before training.

## Approach

**1. Data preparation** — download images from `dataset.csv`, stratified 70/20/10 train/val/test split, resize to 224×224, normalize, and augment (rotation, flip, brightness/contrast).

**2. Exploratory data analysis** — class and demographic distributions, sample REAL vs. FAKE comparisons, correlation between demographics and label.

**3. Feature engineering** — CNN feature extraction (ResNet/VGG), statistical and frequency-domain (FFT) features, GAN-artifact detection.

**4. Model building**
- **Custom CNN** — 4–5 conv blocks (Conv2D → BatchNorm → ReLU → MaxPool), dropout, and a dense classification head, trained from scratch as a baseline
- **Transfer learning** — ResNet50 / VGG16 / EfficientNet-B0 pre-trained on ImageNet, frozen backbone with a fine-tuned classification head
- **Vision Transformer** — ViT-Base or Swin-Tiny with a custom head
- **Ensemble** — weighted average of the top two performing models

**5. Training** — Binary Cross-Entropy loss, Adam/SGD optimizer, `ReduceLROnPlateau` scheduler, batch size 32–64, up to 100 epochs with early stopping, dropout + L2 weight decay + augmentation for regularization.

**6. Evaluation** — accuracy, precision, recall, F1-score, AUC-ROC, confusion matrix, ROC curve, and a breakdown of performance by demographic group.

**7. Interpretation** — Grad-CAM and saliency maps to visualize what the model attends to, plus error analysis on misclassified samples.

**8. Deployment** — model saved in `.pth` format, a standalone inference script, a Streamlit app for interactive predictions, and an optional FastAPI REST endpoint.

```bash
cd deepfake-detection
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Usage

**1. Download and split the data**
```bash
python src/download_images.py --csv dataset.csv --out data/images
python src/preprocess.py --split 0.7 0.2 0.1
```

**2. Train**
```bash
python src/train.py --model resnet50 --epochs 50 --batch-size 32
```

**3. Evaluate**
```bash
python src/evaluate.py --model models/best_model.pth --data data/test.csv
```

**4. Run inference on a new image**
```bash
python src/inference.py --model models/best_model.pth --image path/to/image.jpg
```

**5. Launch the interactive app**
```bash
streamlit run app/streamlit_app.py
```

## Limitations & Future Work

- Performance may vary across demographic subgroups underrepresented in the dataset
- Detection quality is tied to the specific generative methods present in training data, and may not generalize to newer deepfake techniques
- Future work: expand to video-based deepfake detection, test against adversarially perturbed inputs, and explore lighter-weight models for real-time inference

## Ethical Considerations

This project is intended for deepfake **detection** and media-integrity research. Handle image data responsibly, respect the privacy of individuals depicted in the dataset, and avoid using any generated FAKE samples for purposes other than model training/evaluation.
